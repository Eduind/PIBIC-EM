# Sistema de Gerenciamento do Refeitório — IFBA

Projeto desenvolvido por **Eduardo Azevedo**, sob orientação do professor **Cássio Noronha**, como parte do programa **PIBIT-EM** do Instituto Federal da Bahia (IFBA).

## 📌 Sobre o projeto

O projeto consiste no desenvolvimento de uma **solução web para gerenciamento do estoque do serviço de nutrição do IFBA — Campus Eunápolis**, com o objetivo de facilitar o controle, a organização e o acompanhamento dos produtos utilizados pelo refeitório.

Durante o desenvolvimento, foram criados **dois sistemas independentes**:

* **Sistema de gerenciamento de estoque:** aplicação completa e funcional, atualmente em utilização no campus.
* **Sistema de gerenciamento de cardápios:** protótipo funcional desenvolvido para validação das funcionalidades e demonstração da proposta.

## 🛠️ Tecnologias utilizadas

* **PHP**
* **Laravel**

* **HTML**
* **CSS**
* **JavaScript**

Este repositório contém **apenas a versão final dos sistemas desenvolvidos** durante o projeto, não incluindo versões intermediárias ou etapas anteriores do desenvolvimento.
